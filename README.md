# London Office Monitor

伦敦写字楼市场监测 PoC：Python 管理数据、口径、计算和证据，官方 Codex Python SDK 编排受限 Agent，deck.gl + MapLibre 提供子市场地图。

**建设中。尚未声明 Agent、地图或干净环境安装已通过验收。**

首版聚焦 Savills 公开报告中的 City / West End 平均 prime rent、Grade A rent 和整体空置率，以及报告中的需求驱动。历史资料不代表实时行情。Canary Wharf / Midtown & Fringe 缺少同口径资料时保持缺失；地图几何仅为有明确标签的交互示意。

项目仅发布可公开的代码、必要事实摘录与来源说明，不发布原始测评附件、完整研究报告或任何凭据。

项目约定见 `docs/agents/`。后续需求使用 GitHub Issues；当前初始化没有创建 Issue，也没有启动 Ralph。
